¿Qué es el código Morse?

El código Morse es un sistema de comunicación que representa letras y números mediante combinaciones de puntos y rayas.

Un punto representa una señal corta y una raya representa una señal larga.

Ejemplo

La palabra HOLA en código Morse es:

.... --- .-.. .-

¿Cómo funciona?

• Punto: señal corta.

− Raya: señal larga.

Espacio: separa las letras.

/ : separa las palabras.
